# דעת אהרן — אפליקציית Windows

אפליקציית Windows חדשה שנבנית מאפס. הפרויקט שומר על הרעיון הפונקציונלי של מערכת הקישורים, בלי להעתיק קוד או קבצי מקור מהפרויקט הישן.

## מה קיים כרגע בקוד
- ממשק WPF בעברית ובכיווניות RTL.
- הוספה, הצגה, עריכה ומחיקה של קישורים.
- שמירת קישורים מקומית במסד SQLite תחת תיקיית המשתמש.
- פתיחת קישורי HTTP/HTTPS בתוך WebView2.
- בדיקת כתובות וחסימת פרוטוקולים שאינם HTTP/HTTPS.
- חסימת פתיחת חלונות חדשים בדפדפן המוטמע.
- בדיקות יחידה לכתובות קישור.
- בניית CI אוטומטית ב-GitHub Actions.
- תהליך אריזה למתקין Windows ולקובץ ZIP נייד (נדרש עדיין אימות מלא של תהליך ההפצה).

## מבנה
- `src/DaatAharon.App` — ממשק Windows.
- `src/DaatAharon.Core` — מודלים וכללי ליבה.
- `src/DaatAharon.Infrastructure` — אחסון SQLite.
- `tests/DaatAharon.Tests` — בדיקות.

## טכנולוגיות
- C# / .NET 10
- WPF + XAML
- WebView2
- SQLite
- xUnit
- GitHub Actions
- Inno Setup למתקין Windows

## בנייה מקומית
נדרש Windows עם .NET 10 SDK ו-WebView2 Runtime.

```powershell
dotnet restore .\DaatAharon.sln
dotnet build .\DaatAharon.sln -c Release
dotnet test .\DaatAharon.sln -c Release
```

## יצירת מתקין ופרסום גרסה
תהליך ההפצה נמצא ב-`.github/workflows/release.yml` ומיועד לייצר מתקין EXE וקובץ ZIP נייד עבור Windows x64.

כדי לפרסם גרסה:
1. צור תגית כמו `v1.0.0` על commit רצוי.
2. דחוף את התגית ל-GitHub.
3. GitHub Actions יבנה, יבדוק, יארוז ויצור GitHub Release עם קובצי ההפצה.

אפשר גם להפעיל את תהליך האריזה ידנית דרך Actions; במקרה זה הקבצים יישמרו כ-Artifact ולא יפורסמו כ-Release.

## מה עדיין לא הושלם
זהו בסיס בפיתוח, לא מוצר מלא. עדיין נדרשים: מנוע מדיניות מתקדם לאתרים ודומיינים, רשימות חסימה/היתר עם התמדה, ניהול קטגוריות מלא, חיפוש וסינון, כללי הסתרת רכיבי DOM, ייבוא/ייצוא נתונים, גיבוי ושחזור, יומן פעילות, מסכי ניהול, אבחון, ובדיקת התקנה והרצה על מחשב Windows נקי.

אין לפרסם גרסה למשתמשים לפני ש-CI עובר, תהליך יצירת המתקין וה-ZIP עובר, והתקנה והרצה נבדקות בפועל על Windows.
